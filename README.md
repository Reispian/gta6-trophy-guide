An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with cited sources, a roadmap to the platinum, missable flags, filters, a spoiler setting, and progress saved in the browser with export/import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. The app is static files under `app/` and works with the network off.
